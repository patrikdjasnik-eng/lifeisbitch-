# Vlastní výtvarné podklady

`oak-foliage.png` je vlastní generovaná alfa textura listí, vytvořená vestavěným nástrojem imagegen pro tuto hru. Je přibalená lokálně a mapovaná na protínající se plochy korun 3D stromů. Nejde o asset z Lineage II nebo Metinu 2. Kámen a zemina používají deterministické Canvas textury z rendereru. Modely jsou procedurální.

Použitý finální prompt:

> Use case: stylized-concept. Asset type: production game foliage texture with actual transparent background, square 1024x1024. Create one isolated, irregular cluster of many small natural oak leaves and thin branching twigs, seen front-on, occupying 90 percent of canvas, fully detached with softly irregular silhouette and fine gaps between leaves. Realistic classic high-fantasy MMORPG art direction like Lineage II environments: mature muted olive and sage foliage, tiny dry ochre leaf accents, textured natural leaves with visible veins, not cartoon or low-poly. Neutral diffuse overcast lighting, no cast shadow, no bright specular highlights, no scene, no trunk, no ground, no text, no border, no watermark. It will be alpha-tested on intersecting planes in the crown of a 3D tree, so use evenly distributed detailed foliage and transparent holes, preserve a clean alpha silhouette.
